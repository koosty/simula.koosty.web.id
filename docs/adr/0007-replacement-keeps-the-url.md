# Replacing a simulation keeps its URL

When the tool rewrites the content of a published simulation, the file keeps its name and the simulation keeps its URL. A corrected simulation should not lose its search ranking as a side effect of being fixed, and the catalog entry needs no change.

The opposite rule, where changed content counts as a new simulation with a new slug and the old URL left in place, applies only when a genuinely new simulation is derived from an old file; that case gets its own catalog entry. This is hard to reverse, because published URLs outlive any code change, which is why it is recorded here rather than left to the build's behaviour.
