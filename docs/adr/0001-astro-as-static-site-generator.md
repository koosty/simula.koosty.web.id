# Astro as the static site generator

The catalog is foreign-made HTML files plus generated pages, not an application. Astro's content collections give validated front matter and typed queries for the catalog while emitting plain HTML, so no JavaScript framework runtime loads on the Katalog. Simulation files are copied to the output verbatim and never processed. Hugo's taxonomy system would scale better if the catalog grows to thousands of entries, and a plain HTML plus shell-script build would have the fewest dependencies; neither was worth the cost unless the catalog size or the site's simplicity changes.
